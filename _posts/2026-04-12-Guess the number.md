# 파이썬 숫자 맞추기 게임

난이도를 고르면 그 범위에서 **랜덤 정답**이 정해지고, **정답을 맞출 때까지 계속 입력**받는 콘솔 게임입니다.

| 난이도 | 범위 |
|---|---|
| 1. 쉬움 | 1 ~ 10 |
| 2. 보통 | 1 ~ 50 |
| 3. 어려움 | 1 ~ 100 |

## 핵심 포인트

* **`random.randint(1, end)`** 로 정답을 만든다.
* **`while True`** 로 맞출 때까지 반복하고, 맞추면 **`break`** 로 빠져나온다.
* **`try / except`** 로 숫자가 아닌 입력에도 프로그램이 꺼지지 않게 한다.
* **`cnt`** 로 시도 횟수를 세어 결과에 보여준다.

## 전체 코드

```python
import random

print("난이도 선택")
print("1. 1~10")
print("2. 1~50")
print("3. 1~100")

d = int(input("난이도: "))

if d == 1:
    end = 10
elif d == 2:
    end = 50
else:
    end = 100

answer = random.randint(1, end)
print("1부터 " + str(end) + " 사이 숫자 맞춰보세요")

cnt = 0
while True:
    try:
        x = int(input("숫자 입력: "))
        cnt = cnt + 1

        if x < answer:
            print("작음")
        elif x > answer:
            print("큼")
        else:
            print("정답 " + str(cnt) + "번 만에 맞춤")
            break
    except:
        print("숫자를 쓰세요")
```

## 코드 설명

**1. 난이도에 따라 범위 정하기**

선택한 번호에 따라 최대 숫자 `end`가 정해집니다. **1, 2가 아니면 모두 100**으로 처리됩니다.

**2. 정답 만들기**

`random.randint(1, end)`로 1부터 `end` 사이에서 숫자 하나를 뽑아 정답으로 둡니다.

**3. 맞출 때까지 반복**

입력값이 정답보다 작으면 "작음", 크면 "큼"을 알려주고, 같으면 **시도 횟수를 출력한 뒤 `break`로 반복을 끝냅니다.**

**4. 잘못된 입력 처리**

문자를 입력하면 `int()` 변환에서 오류가 나는데, 이를 `except`로 받아 안내 문구만 출력하고 **다시 입력**받습니다.

## 아쉬운 점

* 난이도 입력(`int(input(...))`)은 `try / except` 밖에 있어서 **문자를 넣으면 프로그램이 종료**됩니다.
