# PyQt5 + OpenCV 실시간 웹캠 & 캐니 엣지 검출

웹캠 영상을 화면에 보여주고, **Canny 버튼**을 누르면 **캐니 엣지 검출 결과**를 옆 화면에 함께 보여주는 프로그램입니다.

## 핵심 포인트

* **별도 스레드(`QThread`)** 에서 영상을 처리해서 UI가 멈추지 않는다.
* 영상 처리 객체와 화면(UI)은 **시그널/슬롯**으로 이미지를 주고받는다.
* OpenCV는 **BGR**, Qt는 **RGB** 순서라서 `cvtColor`로 변환해야 한다.
* 캐니 검출은 **흑백 변환 → `cv2.Canny`** 순서로 한다.
* **`flag`** 하나로 엣지 화면을 켜고 끈다.

## 프로그램 구조

| 구성 | 역할 |
|---|---|
| `ShowVideo` | 웹캠에서 프레임을 읽고, 엣지 검출을 하고, 시그널로 내보냄 |
| `ImageViewer` | 받은 이미지를 화면에 그림 (원본용, 엣지용 2개) |
| `main` | 스레드, 시그널 연결, 버튼, 레이아웃 구성 |

## 1. 영상 읽기와 엣지 검출 (`ShowVideo`)

```python
@QtCore.pyqtSlot()
def startVideo(self):
    run_video = True
    while run_video:
        ret, image = self.camera.read()
        color_swapped_image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

        qt_image1 = QtGui.QImage(color_swapped_image.data,
                                 self.width, self.height,
                                 color_swapped_image.strides[0],
                                 QtGui.QImage.Format_RGB888)
        self.VideoSignal1.emit(qt_image1)

        if self.flag:
            img_gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
            img_canny = cv2.Canny(img_gray, 50, 100)
            qt_image2 = QtGui.QImage(img_canny.data,
                                     self.width, self.height,
                                     img_canny.strides[0],
                                     QtGui.QImage.Format_Grayscale8)
            self.VideoSignal2.emit(qt_image2)

        loop = QtCore.QEventLoop()
        QtCore.QTimer.singleShot(25, loop.quit)   # 25ms 대기
        loop.exec_()
```

* 프레임을 읽고 **RGB로 바꿔** `QImage`로 만든 뒤 `VideoSignal1`로 보냅니다.
* `flag`가 켜져 있으면 **흑백 → `Canny(50, 100)`** 결과를 `VideoSignal2`로 보냅니다.
* **25ms 대기**로 초당 약 40프레임 속도를 맞추고, 이벤트 루프가 돌 틈을 줍니다.

```python
@QtCore.pyqtSlot()
def canny(self):
    self.flag = 1 - self.flag     # 0 ↔ 1 토글
```

Canny 버튼을 누를 때마다 `flag`가 **0과 1을 번갈아** 바뀝니다.

## 2. 화면에 그리기 (`ImageViewer`)

```python
@QtCore.pyqtSlot(QtGui.QImage)
def setImage(self, image):
    if image.isNull():
        print("Viewer Dropped frame!")
    self.image = image
    if image.size() != self.size():
        self.setFixedSize(image.size())
    self.update()
```

시그널로 이미지가 들어오면 저장하고 `update()`로 다시 그리게 합니다. **`paintEvent`에서 `drawImage`로 실제 그리기**가 일어납니다.

## 3. 스레드와 연결 (`main`)

```python
thread = QtCore.QThread()
thread.start()
vid = ShowVideo()
vid.moveToThread(thread)          # 영상 처리를 별도 스레드로

vid.VideoSignal1.connect(image_viewer1.setImage)   # 원본 → 뷰어1
vid.VideoSignal2.connect(image_viewer2.setImage)   # 엣지 → 뷰어2

push_button1.clicked.connect(vid.startVideo)       # Start
push_button2.clicked.connect(vid.canny)            # Canny
```

* **`moveToThread`** 로 무한 루프가 메인 UI 스레드를 막지 않게 합니다.
* 뷰어 두 개를 가로로 놓고, 그 아래에 Start / Canny 버튼을 세로로 배치합니다.

## 아쉬운 점

* 웹캠이 없으면 `camera.read()`가 실패해 **시작하자마자 오류**가 납니다. (`ret` 확인 필요)
* `startVideo`의 **루프를 멈추는 방법이 없습니다.** (`run_video`가 항상 `True`)
